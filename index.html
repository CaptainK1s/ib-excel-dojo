House rules the file is built on

  1. One formula, copied across years. If you rewrite FY27 by hand, you already lost.
  2. Assumptions live in one yellow block. The tax rate is not hiding in eleven places.
  3. Units in the header (Revenue ($mm)), not inside the cell.
  4. Custom format $#,##0;($#,##0);"-" — negatives in parentheses, zeros as dashes.
  5. No merged cells in a number grid. They break Ctrl+Arrow.
  6. Build the check tab before the forecast.
  7. Historical = blue hardcodes. Forecast = black formulas.

How to use it this week
